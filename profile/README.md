# no-phux

terminals as objects on a wire

**[phux](https://github.com/no-phux/phux)** is a terminal multiplexer whose panes are a view. Underneath, each terminal is an object on a wire — you, Cockpit, a script, or an agent attach to the same live emulator. Site: [phux.sh](https://phux.sh).

## Repos

- [phux](https://github.com/no-phux/phux) — you and your agents share the same terminals
- [homebrew-tap](https://github.com/no-phux/homebrew-tap) — official Homebrew tap for phux
- [herdr-opencode](https://github.com/no-phux/herdr-opencode) — Herdr lifecycle reporting for OpenCode
- [phux-cockpit](https://github.com/no-phux/phux-cockpit) — archived native GUI cockpit spike

Install: `curl -fsSL https://phux.sh/install | sh` · `brew tap no-phux/tap && brew install no-phux/tap/phux`
